# موقع المستودع (Node.js + Express + MySQL)

## التشغيل
1. أنشئ قاعدة البيانات: استورد `schema.sql` من phpMyAdmin (أو `mysql -u root -p < schema.sql`)
2. `npm install`
3. `npm start` ثم افتح http://localhost:3000

متغيرات البيئة (اختيارية): `DB_HOST` `DB_USER` `DB_PASS` `DB_NAME` `PORT`

## الميزات
- جدول الأصناف (إضافة وحذف)
- نموذج طلب صرف: اسم الطالب، العدد، اسم المسلِّم
- خصم الكمية تلقائياً وتسجيل الطلب في سجل الصرف
- تنبيه آلي (شريط وإشعار وسجل) عند وصول الكمية للحد الحرج

## الهيكل
- `server.js`: الخادم وواجهات API
- `schema.sql`: ملف بناء قاعدة البيانات
- `public/index.html`: الواجهة

## الأمان
- Prepared Statements (منع SQL Injection)
- تنظيف المدخلات وتهريب النصوص في الواجهة (منع XSS)
- التحقق من أن الأعداد أرقام صحيحة موجبة، ومنع صرف أكثر من المتوفر
- خصم المخزون داخل Transaction مع قفل الصف لمنع التعارض
